## 👋 Cuando Regreses - 3 Pasos Simples

### Paso 1️⃣: Obtén las Credenciales

Ve a estos sitios y copia 4 valores:

| Sitio | Qué Copiar | Dónde |
|---|---|---|

| **Supabase** | Service role key | Settings → API → service_role |
| **Claude API** | API key | console.anthropic.com → Create Key |

**Tiempo:** ~10 minutos

```bash

npm run setup-wizard
```

Solo copia y pega los 4 valores que obtuviste.

**El wizard automáticamente:**
- ✅ Crea `.env.local`
- ✅ Valida credenciales
- ✅ Te muestra qué hacer después

**Tiempo:** ~2 minutos

### Paso 3️⃣: Sigue las Instrucciones del Wizard

El wizard te dirá exactamente:

```
1. npm install -g supabase
2. supabase login
3. supabase link --project-ref PROJECT_ID
4. supabase db push
5. npm run dev
6. Abre http://localhost:3000
7. ¡Crea una cuenta y prueba!
8. git push origin main
```

**Tiempo:** ~10 minutos
