# QuizMaster - Plataforma Educativa Interactiva

Una aplicación tipo Kahoot moderna para educadores, que permite crear actividades competitivas en tiempo real con puntuaciones y sistemas de premios.

## Características

- 🎮 Competencias en tiempo real (individual o grupos)
- 🤖 Asistente IA para generar preguntas
- 🏆 Sistema de puntuaciones y premios canjeables
- 📊 Reportes y estadísticas detalladas
- 🌙 Modo oscuro/claro
- 📱 Responsive (desktop y mobile)
- 🔌 Funciona online y parcialmente offline
- ♿ Accesible (WCAG 2.1 AA)

## Tech Stack

- **Frontend:** Next.js 14, React, TypeScript, Tailwind CSS
- **Backend:** Supabase (PostgreSQL, Real-time)
- **IA:** Claude API
- **Deploy:** Vercel
